## Five Technical Experience Answers

### 1. AI Agent Development

`[CANDIDATE INPUT REQUIRED]` — Provide the strongest real project the candidate
personally built. Explain the problem, actual LLMs/APIs/frameworks/tools,
tool-calling and orchestration, personal implementation, and whether it was a
prototype or deployed application. Clearly separate completed features from
planned or partially implemented features.

### 2. Technical Challenges & Problem-Solving

`[CANDIDATE INPUT REQUIRED]` — Select one real technical failure from an AI agent
or LLM-powered application. State what failed, how the root cause was isolated,
the exact change made, and how the fix was verified. Include logs, tests,
reproduction steps, or code evidence where available.

### 3. Full-Stack Development Experience

`[CANDIDATE INPUT REQUIRED]` — Select a real application/feature and describe
frontend, backend, database, validation, errors, and tests. State actual
languages/frameworks/database used (do NOT assume C#/.NET/SQL Server). Explain
the data flow from UI to API to database and back, using a concrete feature.
State actual testing performed; distinguish automated tests from manual checks.

### 4. AI Agent Reliability & Security

`[CANDIDATE INPUT REQUIRED]` — Give one concrete example from actual development
involving unreliable model output, failed tools, incorrect actions, prompt
injection, data exposure, validation, or bounded retries. Explain the guardrail
and how it was tested. If the candidate has not implemented a particular
safeguard, say what was implemented and identify the rest as a future improvement.

### 5. AI-Assisted Development & Code Quality

`[CANDIDATE INPUT REQUIRED]` — Name only AI coding tools actually used. Explain
the candidate's review process: inspect generated diffs, understand changes,
run tests/type checks/lint/build, review security and edge cases, and reject
unsupported changes. Give one real example of catching or correcting
generated-code problems if available.

## Candidate Confirmation Required

The following factual statements require the candidate's explicit approval
before submission:

1. All form fields (name, contact, location, LinkedIn/GitHub, experience,
   notice period, availability).
2. Every statement in answers 1–5 that asserts personal implementation
   ("I implemented", "I built", "I tested").
3. Any numbers, dates, or metrics used in the answers.
4. Confirmation that no employer or confidential code is included.
